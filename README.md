Login Form Task

Project Description

A simple Java Login Form with authentication and role-based login using Java AWT.

Features

- Check that username and password fields are not empty.
- Verify that the user exists.
- Validate the password.
- Display error messages for invalid login information.
- Support three user roles: Student, TA, and Professor.
- Disable the Login button after 3 incorrect password attempts.

Technologies Used

- Java
- Java AWT
- Object-Oriented Programming (OOP)

How to Run

1. Download the project.
2. Open "LoginFormTask_completed.java" in a Java IDE.
3. Compile and run the file.
